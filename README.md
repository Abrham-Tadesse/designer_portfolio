# Designer Portfolio

React + Vite + Tailwind CSS portfolio for a graphic designer.

## Run

```bash
npm install
npm run dev
```

## Personalize first

- `src/data/projects.js` — project titles, descriptions and case-study content.
- `public/images/` — replace placeholder SVG files with the designer's real work.
- `src/components/layout/Navbar.jsx` — designer/studio name.
- `src/components/layout/Footer.jsx` — social links.
- `src/pages/About.jsx` — biography, portrait and tools.
- `src/pages/Contact.jsx` — email and contact text.

Tailwind uses the current first-party Vite plugin.
